# Central de Trabalho | Claro

Portal único de ferramentas, rotina, produtividade, alertas e exportação do calendário semanal.

## Publicação
Envie todo o conteúdo desta pasta para a raiz do repositório e publique no GitHub Pages pela branch `main`, pasta `/root`.

## Exportação
Na página Calendário, use **Baixar Excel** para gerar um arquivo `.xls` compatível com Excel e **Baixar PDF** para abrir a impressão do navegador, escolhendo **Salvar como PDF**.
